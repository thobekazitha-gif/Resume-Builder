**Program:** Tech Career Accelerator (CAPACITI)

**Sector/Application:** Career Services / Recruitment  
**Team Size:** Group Project  

🔗 **Public Access Link:**  
[Logic League Resume Builder](https://logic-league-one.vercel.app/)

---

## Project Overview

The **AI Resume Builder** is an intelligent system designed to help users create customized, ATS-friendly resumes efficiently. It generates tailored content based on user career information, optimizes resumes with industry-specific keywords, checks for ATS compatibility, and provides multiple format export options (PDF, DOCX, HTML). The tool also includes smart suggestions based on job roles and industries, improving outputs through a feedback loop as users edit their resumes.

---

## Objectives

- Generate professional resumes based on user career inputs  
- Ensure ATS compatibility and keyword optimization for different industries  
- Provide multiple export formats (PDF, DOCX, HTML)  
- Offer multiple visual templates with customization options  
- Implement a feedback mechanism to improve AI-generated content  

---

## Features

### Core Features
- **Customizable Templates:** At least 3 distinct visual templates  
- **Content Generation:** Tailored to user career history, skills, and industry  
- **ATS Optimization:** Ensures resumes pass automated tracking systems  
- **Job Description Matching:** Highlights relevant skills and experience  
- **Feedback Loop:** Improves outputs based on user edits  
- **Export Options:** PDF, DOCX, HTML  
- **Preview Functionality:** Section-by-section resume preview  
- **Local Data Storage:** Ensures user privacy  

---

## Technical Specifications

- **Frontend:** Clean, responsive interface with cross-browser compatibility  
- **AI Integration:** Generative AI API for content generation and optimization  
- **Local Storage:** User data saved securely in the browser  
- **Template Design:** Multiple visual templates with customization (font, layout, colors)  
- **Performance Optimization:** Fast generation times and efficient API usage  
- **Documentation:** Clear explanation of API usage, limitations, and architecture  

---

## Implementation Details

### User Flow
1. User enters personal, educational, and career information  
2. AI generates resume content tailored to the selected job role or industry  
3. User previews and edits sections if needed  
4. Feedback loop improves AI suggestions based on edits  
5. User selects a template and exports the resume in the preferred format  

### Technical Stack
- Frontend: HTML, CSS, JavaScript (or no-code workflow if applicable)  
- Backend/AI: OpenAI API or similar generative AI service  
- Storage: Local browser storage for privacy  
- Export: PDF, DOCX, HTML rendering libraries
